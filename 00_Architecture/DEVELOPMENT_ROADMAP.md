# AITOS v2 Development Roadmap

The roadmap follows strict dependency order so that each phase can be built and tested without stubs for downstream modules.

## Phase 1 – Market Foundations
**Goal:** Build all market analysis capabilities necessary to produce a unified market context.
*   AITOS-MICRO-08
*   AITOS-EXOTC-09
*   AITOS-SESSION-10
*   AITOS-MEF-07
*   AITOS-MSTRUCT-11
*   AITOS-CTA-12
*   AITOS-WYCKOFF-13
*   AITOS-SMC

## Phase 2 – Decision Layer
**Goal:** Create the Context Engine that normalizes all analysis, and the Alpha Engine that generates initial trading signals.
*   AITOS-CONTEXT
*   AITOS-ALPHA

## Phase 3 – Risk Layer
**Goal:** Build risk evaluation and constraint generation.
*   AITOS-RISK

## Phase 4 – Portfolio Layer
**Goal:** Construct optimal portfolios under risk constraints.
*   AITOS-PORT

## Phase 5 – Execution Layer
**Goal:** Implement smart order routing and execution.
*   AITOS-EXEC

## Phase 6 – Observability Layer
**Goal:** Provide system‑wide monitoring, logging, and alerting.
*   AITOS-MONITOR

## Phase 7 – Continuous Learning Layer
**Goal:** Enable online and batch learning pipelines that improve all trainable modules.
*   AITOS-LEARN

## Phase 8 – AI Supervisory Layer

## Phase 9 – Self-Evolution Layer (AITOS Dev Agent)
**Goal:** Build the development agent that manages the repository and documentation.
*   AITOS-DEV-AGENT
**Goal:** Integrate a high‑level AI decision maker that can override automated decisions based on holistic reasoning.
*   AITOS-AI
