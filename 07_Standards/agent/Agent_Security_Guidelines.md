# إرشادات الأمان لوكيل تطوير AITOS (AITOS Dev Agent Security Guidelines)

تحدد هذه الوثيقة معايير الأمان والخصوصية لعمل الوكيل.

## 1. إدارة الأسرار (Secrets Management)
*   يجب عدم تخزين أي رموز وصول (Tokens) أو مفاتيح API بشكل نصي داخل المستودع.
*   يجب استخدام GitHub Secrets أو بيئة آمنة لإدارة رموز الوصول.

## 2. مراجعة الصلاحيات (Permissions Audit)
*   يجب مراجعة صلاحيات الوكيل بشكل دوري لضمان بقائها ضمن حدود "أقل الصلاحيات".
*   يجب تسجيل جميع استدعاءات API التي يجريها الوكيل.

## 3. التحقق من الهوية (Authentication)
*   يجب أن يستخدم الوكيل GitHub App أو Personal Access Token (PAT) بمدة صلاحية محدودة.
*   يجب أن يتم توقيع جميع الـ Commits التي يجريها الوكيل.

## 4. الحماية من الهجمات (Protection)
*   يجب أن يكون الوكيل قادراً على اكتشاف ومنع محاولات حقن الأوامر (Command Injection) في المهام الموكلة إليه.
*   يجب فحص جميع المدخلات الخارجية التي يتلقاها الوكيل.
